# Machine Condition Monitoring

## Overview
Machine Condition Monitoring is a Flutter-based mobile application designed to monitor the health and status of industrial machines. The application provides a simple user interface for displaying machine information and can be extended to support real-time sensor data, alerts, and predictive maintenance.

## Features
- User-friendly Flutter interface
- Cross-platform support (Android, Windows, Web)
- Real-time machine status monitoring (Future Enhancement)
- Sensor data visualization (Future Enhancement)
- Maintenance alerts and notifications (Future Enhancement)

## Technologies Used
- Flutter
- Dart
- Android SDK
- Visual Studio Code

## Requirements
- Flutter SDK (3.x or later)
- Dart SDK
- Android Studio or VS Code
- Android SDK
- Chrome (for web testing)

## Installation

1. Clone the repository.
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder.
   ```bash
   cd machine_condition_monitoring
   ```

3. Install dependencies.
   ```bash
   flutter pub get
   ```

4. Run the application.
   ```bash
   flutter run
   ```
